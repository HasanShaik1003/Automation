# 🧪 Automation Project

## Overview
This project contains **UI Automation scripts** developed using **Java, Selenium, and the Page Object Model (POM)** design pattern.

---

## 🔍 Scope of Automation

The following functionalities have been automated:

1. **Manager Login**
    - Verify login functionality with positive and negative test cases.
    - Ensure all fields are responsive on the Manager Home Page.

2. **Manager Leave Request**
    - Verify that a manager can apply for a new leave.
    - Check whether the leave request is **auto-approved** (shows “Request has been auto approved!”).

3. **Employee Login**
    - Verify employee login functionality.
    - Ensure all fields are responsive on the Employee Home Page.

4. **Employee Leave Request**
    - Verify that an employee can apply for a new leave.
    - Ensure that the message **“Request has been submitted”** is displayed.

---

## 🧩 Test Summary

- **Total Test Cases Automated:** 11
- **Automation Framework:** Selenium + TestNG + POM + Extent Reports 
- **Language:** Java
